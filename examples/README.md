# Example Fixtures and Reports

- [`synthetic-bars.csv`](./synthetic-bars.csv) is a fictional OHLCV series for exercising the CSV loader and council orchestration.
- [`research-context.synthetic.json`](./research-context.synthetic.json) is a fictional, explicitly labelled research-context input. The `.invalid` URLs are placeholders and are not sources.
- [`sample-report.md`](./sample-report.md) is a generated offline council report using the synthetic OHLCV fixture.
- [`sample-context-report.md`](./sample-context-report.md) is a generated report showing the context section names attached to the run.

None of these files contain live market observations or trading recommendations.
