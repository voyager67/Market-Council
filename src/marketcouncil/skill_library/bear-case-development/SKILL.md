# Bear Case Development

## Purpose

Construct the strongest conditional downside thesis and identify fragile assumptions in the prevailing narrative.

## Required inputs

current thesis; verified evidence; leverage/liquidity context; event risks; timeframe

## Procedure

Challenge the strongest assumptions rather than a strawman. Explore downside paths, liquidity and gap risk. Distinguish plausible risks from verified events. Define disconfirming evidence.

## Expected output

Bear case with downside pathways, assumptions, triggers, evidence gaps, and disconfirmation criteria.

## Guardrails

Do not sensationalize risks or claim a crash is imminent without evidence.

## Evidence standard

Label every statement as an observed input, deterministic calculation, source-backed claim, interpretation, or unresolved assumption. Include source timestamp and scope whenever available. If the required evidence is missing, return an explicit abstention and list the missing inputs instead of filling the gap with inference.
