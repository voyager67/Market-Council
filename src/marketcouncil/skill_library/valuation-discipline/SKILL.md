# Valuation Discipline

## Purpose

Frame valuation using explicit assumptions, comparable sets, and scenario ranges rather than false precision.

## Required inputs

verified financials; share count; debt/cash; comparable set; forecast assumptions; valuation date

## Procedure

Choose methods suited to business economics. Record source dates and currency. Show major assumptions and sensitivity. Explain multiple selection and peer comparability. Identify reverse-valuation implications where useful.

## Expected output

Valuation memo with scenarios, key assumptions, sensitivity table, limitations, and evidence gaps.

## Guardrails

A valuation output is not a price target guarantee. Never present unsupported forecasts or single-point certainty.

## Evidence standard

Label every statement as an observed input, deterministic calculation, source-backed claim, interpretation, or unresolved assumption. Include source timestamp and scope whenever available. If the required evidence is missing, return an explicit abstention and list the missing inputs instead of filling the gap with inference.
