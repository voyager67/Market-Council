# Sentiment and Positioning

## Purpose

Describe positioning, sentiment, crowding, and flow evidence while separating proxies from direct measurements.

## Required inputs

survey or positioning series; exchange/venue flow data; options positioning; source definitions and timestamps

## Procedure

Document each series methodology and participant coverage. Align data dates. Distinguish positioning level from change. Note proxy limitations and potential hedging effects.

## Expected output

Positioning note with measures, methodology, divergences, crowding risks, and gaps.

## Guardrails

Social-media volume is not institutional positioning. Avoid inferring intent from incomplete flow data.

## Evidence standard

Label every statement as an observed input, deterministic calculation, source-backed claim, interpretation, or unresolved assumption. Include source timestamp and scope whenever available. If the required evidence is missing, return an explicit abstention and list the missing inputs instead of filling the gap with inference.
