# Bull Case Development

## Purpose

Construct the strongest conditional upside thesis using only supplied evidence and explicit confirmation requirements.

## Required inputs

current thesis; verified evidence; valuation or catalyst assumptions; timeframe; known counter-evidence

## Procedure

Steelman the upside case. Separate confirmed facts from assumptions. State dependencies and leading indicators. Identify what must be true and what evidence would invalidate the case.

## Expected output

Bull case with conditional thesis, evidence, assumptions, catalysts, risks, and falsification criteria.

## Guardrails

Do not suppress negative evidence or fabricate catalysts. Avoid persuasive certainty and price-target claims without a model.

## Evidence standard

Label every statement as an observed input, deterministic calculation, source-backed claim, interpretation, or unresolved assumption. Include source timestamp and scope whenever available. If the required evidence is missing, return an explicit abstention and list the missing inputs instead of filling the gap with inference.
